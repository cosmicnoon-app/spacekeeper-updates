# SpaceKeeper updates

Official update feed and release downloads for **SpaceKeeper**, free macOS software by [Cosmic Noon](https://cosmicnoon.com.au).

- [Update feed](https://cosmicnoon-app.github.io/spacekeeper-updates/appcast.xml)
- [Releases](https://github.com/cosmicnoon-app/spacekeeper-updates/releases)
- Once released: [Download SpaceKeeper.dmg](https://github.com/cosmicnoon-app/spacekeeper-updates/releases/latest/download/SpaceKeeper.dmg)

This repository is exclusively for SpaceKeeper. It contains no app source, signing keys, credentials, or updates for other products. Releases use Apple Developer ID signing, notarization and a dedicated Sparkle Ed25519 signing key. No release has been published yet.

The appcast is maintained by SpaceKeeper's release script. Do not change an existing release binary or reuse a build number.
